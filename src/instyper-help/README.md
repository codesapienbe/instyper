# Instyper Help Web App

This module provides a Streamlit-based web app for Instyper help, downloads, and features, inspired by the FreeTube website.

## How to run

1. Install dependencies from the project root:
   ```bash
   pip install -r requirements.txt  # or use pyproject.toml
   ```
2. Run the web app:
   ```bash
   streamlit run __init__.py
   ```
3. Open the provided local URL in your browser.
